## Steps

| Step | What is measured |
|------|------------------|
| Lex | `Curlybars::Lexer.lex`: source to tokens. |
| Parse | `Curlybars::Parser.parse`: tokens to syntax tree. |
| Compile | `Node::Root#compile`: syntax tree to Ruby code. |
| Eval | `Kernel#eval`: Ruby code to a lambda. Ruby parses the generated code; ActionView does this once per template. |
| Render | Calling the lambda: renders the template, including its partials. |
| Render with ActionView | `ActionView::Base#render` of the template through `Curlybars::TemplateHandler`, including setting up the presenter. |
